### Starting with the project:

1. After cloning the project. 
2. Configure the backend with making sure that your appsettings.json is configured with the correct settings for the connection string. 
3. Make sure to run the command flutter pub get.
4. Run the application.

### Description:

A Communication app, that enables users to chat with one another then also to create events. The user role that can organize a event is the Prenium user. The other user types that are Free Users can not organize or create events.
